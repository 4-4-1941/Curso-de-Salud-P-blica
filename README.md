# Curso de Salud Pública

Curso virtual de nivel **inductivo-intermedio**, orientado a comprender y aplicar fundamentos de salud pública en el contexto sanitario peruano.

## Estado

Inicio de construcción del proyecto.

Archivos base:

- `index.html` — portada y estructura inicial del curso.
- `styles.css` — diseño responsive y mobile-first.
- `README.md` — alcance, metodología y reglas documentales del proyecto.

En esta etapa no se incorpora JavaScript porque todavía no existe una funcionalidad que lo requiera.

## Modalidad y enfoque

- 100 % virtual.
- Organización modular.
- Nivel inductivo-intermedio.
- Lenguaje comprensible con rigor técnico.
- Orientación práctica al sistema de salud peruano.
- Casos y ejercicios aplicados.
- Fuentes trazables y verificables.

## Módulos

1. **Políticas de Salud y Sistema Sanitario Peruano**
2. **Epidemiología y Bioestadística Aplicada**
3. **Gestión de Servicios de Salud**
4. **Promoción de la Salud y Atención Primaria**
5. **Salud Ambiental, Ocupacional y Emergencias**
6. **Integración Aplicada en Salud Pública**

## Ruta pedagógica

Cada módulo seguirá una secuencia común:

`Introducción → objetivos → clases → recursos → actividades → caso aplicado → evaluación → cierre`

Cada clase deberá integrar, según corresponda:

1. Objetivo de aprendizaje.
2. Conceptos indispensables.
3. Desarrollo progresivo del tema.
4. Contexto y aplicación en el Perú.
5. Marco normativo o técnico.
6. Caso o situación aplicada.
7. Actividad breve.
8. Idea clave.
9. Autoevaluación.
10. Lecturas y documentos.
11. Referencias APA 7.

## Regla documental

El contenido académico no se incorporará a partir de suposiciones ni de referencias no comprobadas.

Flujo obligatorio:

`LOCALIZAR → ABRIR → VERIFICAR → CONTRASTAR → EXTRAER → CITAR → INCORPORAR`

Cuando el documento completo esté disponible públicamente, debe revisarse antes de afirmar que su contenido fue comprobado. Si únicamente se accede a una ficha, catálogo, resumen o referencia, esto no equivale a haber revisado el documento completo.

### Prioridad de fuentes

1. Normativa y documentos oficiales: MINSA, CDC Perú, INS, SIS, SUSALUD, MEF, INEI y otras entidades públicas competentes.
2. OMS, OPS y organismos técnicos pertinentes.
3. Literatura científica revisada por pares.
4. Investigaciones con DOI u otro identificador verificable.

Las referencias académicas se presentarán en formato **APA 7** y, cuando exista, con enlace a la fuente institucional o DOI.

## Principio de trazabilidad

Debe diferenciarse claramente entre:

- disposición normativa;
- información institucional;
- evidencia científica;
- explicación pedagógica;
- ejemplo o caso didáctico.

Los casos ficticios deberán identificarse como tales. Los datos reales deberán conservar su fuente, población, territorio y periodo.

## Desarrollo técnico

La primera versión utiliza HTML y CSS sin frameworks ni dependencias externas. La incorporación de JavaScript, almacenamiento, backend o servicios externos se realizará únicamente cuando una funcionalidad concreta lo justifique.

## Accesibilidad y dispositivos

La interfaz se desarrolla con enfoque **mobile-first**, navegación mediante teclado, HTML semántico, contraste legible y adaptación a teléfonos, tabletas y computadoras.
